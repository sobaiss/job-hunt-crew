## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (sobaiss/job-hunt-crew), via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default triage label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context layout: a root `CONTEXT-MAP.md` pointing to per-context `CONTEXT.md` files under each app/service. See `docs/agents/domain.md`.
